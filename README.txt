Tiny World V5.4 — WORLD SCALE

DEFAULT WORLD
- New worlds now start at 200×200.

WORLD CREATOR SIZES
- 100×100 — Tiny
- 150×150 — Small
- 200×200 — Standard
- 300×300 — Large
- 500×500 — Huge

The selected size changes the REAL simulation grid. Surface, underground, terrain canvases, resources, camera bounds and Atlas all resize together.

SCALING
- Larger maps receive proportionally more wildlife.
- Long-term population cap increases on larger worlds.
- 500×500 contains 250,000 simulation cells.
- 500×500 uses a lighter backing texture scale to reduce iPhone render/memory pressure while preserving the full simulation grid.

WORLD RESET
- Remembers and recreates the original selected world size.

All V5.3 Family & Marriage and earlier systems remain.
